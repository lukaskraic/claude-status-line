# Status Line Output Examples

What the status line displays in different scenarios.

## Format

```
~/directory (git-branch) [Model Name] INDICATOR XXk/YYYk (ZZ%) · 5h NN% 7d NN%
```

Components:
- `~/directory` - Current working directory with home expansion
- `(git-branch)` - Git branch name (only in git repositories)
- `[Model Name]` - Claude model being used
- `INDICATOR` - Visual usage indicator (✓, ⚠, or ⚠⚠)
- `XXk/YYYk` - Tokens used / effective window (full window minus auto-compact buffer)
- `(ZZ%)` - Percentage of the effective window used
- `· 5h NN% 7d NN%` - Account rate limits, appended only above 80%

The denominator is the effective window, not the raw one: 167k on a 200k model,
967k on a 1M model, assuming the default 33k auto-compact buffer.

## Usage Progression

A 200k window, auto-compact fires at 167k:

```
~/myapp (main) [Sonnet 5] ✓ 3k/167k (2%)         fresh conversation
~/myapp (main) [Sonnet 5] ✓ 28k/167k (17%)       after a few exchanges
~/myapp (main) [Sonnet 5] ✓ 67k/167k (40%)       mid-conversation
~/myapp (main) [Sonnet 5] ⚠ 130k/167k (78%)      approaching auto-compact
~/myapp (main) [Sonnet 5] ⚠⚠ 155k/167k (93%)     auto-compact imminent
```

The same conversation lengths on a 1M window:

```
~/myapp (main) [Opus 5] ✓ 138k/967k (14%)
~/myapp (main) [Opus 5] ⚠ 750k/967k (78%)
~/myapp (main) [Opus 5] ⚠⚠ 900k/967k (93%)
```

## Visual Indicator Thresholds

| Indicator | Range | Meaning |
|-----------|-------|---------|
| ✓ | 0-74% | Safe - plenty of context left |
| ⚠ | 75-89% | Warning - approaching auto-compact |
| ⚠⚠ | 90-100% | Critical - auto-compact imminent |

## Scenarios

### Not in a git repository
```
~/Downloads [Haiku 4.5] ✓ 34k/167k (20%)
```

### Detached HEAD (rebase, bisect)
```
~/project [Sonnet 5] ✓ 34k/167k (20%)
```
Branch is omitted, same as outside a repository.

### Deep path
```
~/Work/clients/acme/projects/web-redesign/src (feature/navbar) [Sonnet 5] ✓ 89k/167k (53%)
```

### System path (no ~ expansion)
```
/etc [Sonnet 5] ⚠ 130k/167k (78%)
```

### Rate limits running low
```
~/myapp (main) [Opus 5] ⚠ 750k/967k (78%) · 5h 82% 7d 50%
```
Appears once either window crosses `RATE_LIMIT_WARN_PCT` (default 80).

### Auto-compact disabled
```
~/myapp (main) [Opus 5] ⚠ 750k/1000k (75%)
```
With `autoCompactEnabled: false`, there is no buffer and the full window is the budget.

### Custom auto-compact window
```
~/myapp (main) [Opus 5] ⚠⚠ 450k/500k (90%)
```
With `CLAUDE_CODE_AUTO_COMPACT_WINDOW=500000` or `/autocompact 500k`.

### Over the effective window
```
~/myapp (main) [Opus 5] ⚠⚠ 980k/967k (100%)
```
Percentage is capped at 100%; auto-compact has not run yet. Run `/compact`.

## Degraded Input

### No context_window in the payload
```
~/project (main) [Sonnet 5]
```
Claude Code older than 2.1.6. The token segment is omitted rather than guessed.

### No usable payload at all
```
 [?]
```
`jq` missing, or stdin was empty or malformed.

## Notes

1. Token counts are truncated to whole thousands (`138419` → `138k`)
2. Percentages are rounded to the nearest whole number
3. Path always uses `~` expansion for the home directory
4. The script keeps no state between invocations — every line is derived from the
   payload Claude Code just handed it
