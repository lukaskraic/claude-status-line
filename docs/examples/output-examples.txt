# Status Line Output Examples

## Format

~/directory (git-branch) [Model] INDICATOR XXk/YYYk (ZZ%) · Session S% (reset 1h23m) · Week W%

- ~/directory          Current directory, $HOME shown as ~
- (git-branch)         Only inside a git repo
- [Model]              Model display name
- INDICATOR            ✓ <75%, ⚠ 75-89%, ⚠⚠ ≥90% of the effective budget
- XXk/YYYk (ZZ%)       Tokens in context / (window - 33k auto-compact buffer)
- Session S%           5-hour rate-limit usage (Pro/Max only)
- (reset 1h23m)        Time until the 5-hour window resets
- Week W%              7-day rate-limit usage (Pro/Max only)
- ⚠ before S% / W%     Limit at 80% or more

## Examples

Fresh conversation, 1M window, Max subscription:
~/Work/myproject (main) [Opus 5] ✓ 139k/967k (14%) · Session 14% (reset 2h05m) · Week 9%

200k window, context filling up, session limit close:
~/Documents (develop) [Sonnet 5] ⚠ 140k/167k (84%) · Session ⚠86% (reset 42m) · Week 31%

Auto-compact imminent, weekly limit close:
~/Work/api (feature/auth) [Opus 5] ⚠⚠ 155k/167k (93%) · Session 40% (reset 3h10m) · Week ⚠91%

Reset time already passed, waiting for next response to refresh:
~/Work/myproject (main) [Opus 5] ✓ 52k/967k (5%) · Session 62% · Week 12%

API key (no rate limits):
~/scripts [Haiku 5] ✓ 23k/167k (14%)

Auto-compact disabled (autoCompactEnabled: false) - full window is the budget:
~/Work/myproject (main) [Sonnet 5] ✓ 45k/200k (22%) · Session 5% (reset 4h50m) · Week 2%

New conversation, no response yet / Claude Code < 2.1.6:
~/Work/myproject (main) [Opus 5]
